# Datenprüfung

Browser-Vorschau der neuen Seite mit der vorhandenen Sidebar bei 1280 × 900 Pixeln. Die Aufnahme verwendet ausschließlich synthetische Personen und Zeiträume. Sie zeigt eine Überschneidung aus einem früheren Jahr und einen zusammengefassten Hinweis auf gleichnamige Personen.

Filter, Suche und die Auswahl der Zielperson wurden in der Browser-Vorschau bedient. Die Navigation zur Historie ist im Renderer angebunden; die Vorschau ersetzt keinen vollständigen nativen Electron-Durchlauf.
