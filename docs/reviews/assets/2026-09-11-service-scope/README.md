# Serviceumfang: synthetischer Vorher/Nachher-Beleg

Die Bilder zeigen dieselbe synthetische Person im bestehenden ClearDeck-Dialog.

- `before-legacy-selector.png`: alte einzelne Auswahl für die MD-Personenliste.
- `after-picker-closed.png`: neue kompakte Auswahl mit sichtbarer Kurzfassung.
- `after-picker-open.png`: aufgeklappte Auswahl mit Suche und §36-Katalogleistungen.

Die Vorheransicht ist eine synthetische Rekonstruktion des alten Auswahlzustands. Die Nachheransichten stammen aus dem gebündelten aktuellen `PatientModal` mit den vereinbarten Katalogleistungen.
